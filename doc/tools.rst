.. _ant_tools:

Tools
#####

.. contents::
   :local:
   :depth: 2

Speed up your development by using the best ANT tool for the task.

.. note::
   These tools are designed to run under Windows.

Download
********
ANT Development tools are available as a **Software Tools** bundle here:
https://developer.garmin.com/ant-program/downloads/


ANTware II
**********

.. list-table::
   :widths: 35 65
   :width: 100%

   * - .. image:: img/ANTwareII-screenshot.png
          :width: 400px
          :alt: ANTware II
     - **Do use this for:**

       - Developing and testing ANT configurations
       - Learning about ANT

       **Don't use this for:**

       - Working with ANT+ devices — while possible, the task will be faster using SimulANT+

SimulANT+
*********

.. list-table::
   :widths: 35 65
   :width: 100%

   * - .. image:: img/SimulANTplus-Screenshot.png
          :width: 400px
          :alt: SimulANT+
     - **Do use this for:**

       - Receiving from ANT+ devices
       - Sending simulated ANT+ data to a display device
       - Developing and testing your ANT+ product

       **Don't use this for:**

       - Reverse engineering ANT+ devices — coding directly from the ANT+ Device Profile is typically simpler and faster
